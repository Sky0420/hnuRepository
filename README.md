# La Baroque Created by 홍길동

바로크 스타일의 분위기를 적용한 카페 소개 홈페이지입니다. 별도의 프레임워크 없이 HTML, CSS, JavaScript만으로 제작했습니다.

## 주요 기능

- 바로크 스타일의 고급스러운 카페 디자인
- 카페 소개 및 시그니처 메뉴 4종 안내
- 운영 시간과 위치, 예약 전화번호 표시
- 다크모드/라이트모드 토글 및 선택 상태 저장
- 데스크톱과 모바일을 고려한 반응형 레이아웃
- 메뉴 카드 클릭 시 안내 알림 표시

## 실행 방법

1. 저장소를 내려받습니다.
2. `index.html` 파일을 웹 브라우저로 엽니다.

## 프로젝트 구성

- `index.html`: 전체 페이지 구조, 스타일, JavaScript
- `README.md`: 프로젝트 설명
